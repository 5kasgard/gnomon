# Prompts used for the end-to-end QA runs (2026-10-21)

All three conditions used Claude Haiku (claude-haiku-5-5) as a sub-agent,
one agent per condition, with no access to gold answers or to the other
conditions' files. The instructions, verbatim apart from file paths:

**memory (k=10) and memory30 (k=30):** "For each question, answer from its
own memory snippets only, as briefly as possible (a few words: a name, a
date, a short phrase). Resolve relative dates ("last year", "yesterday")
against the snippet's date and give an absolute date or year. If the
snippets do not contain the answer, answer exactly "Not mentioned"." The
agent was told not to open gold.json, the transcripts or other answer
files, and not to write code to answer.

**full:** "Process one conversation at a time: read the whole
conv<N>.txt, then answer every question whose conv is N, using that
transcript. Answer as briefly as possible (a few words: a name, a date, a
short phrase). Resolve relative dates against the session's date and give
an absolute date or year. If the transcript does not contain the answer,
answer exactly "Not mentioned"." Same restrictions.

The questions: 40 random answerable questions (categories 1-4) and 10
random adversarial ones (category 5) from each of LoCoMo conversations 5-9,
seed 20261021 (bench/qa is generated by the snippet in the commit that
added it; the files themselves hold LoCoMo text, CC BY-NC 4.0, and are not
redistributed).

The memory30 condition was answered in two agent sessions (120 questions,
then the remaining 130 after the first session stopped), with the same
instructions.
